# 📂 Website Asset Folder Structure

All assets for the website are neatly organized into section folders for easy maintenance:

- **`src/assets/hero/`**: Hero section background image (`hero_background.png`).
- **`src/assets/about/`**: About section portrait image (`pic_red_kurta.png`).
- **`src/assets/gallery/`**: Photos for Visual Gallery & Audio repertoire (`pic_mic_black.png`, `pic_singing_mic.png`, `pic_tshirt.png`).
- **`src/assets/social_feeds/`**: Social media post thumbnails and channel assets.
